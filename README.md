## طريقة التوثيق

كل لاب يتبع القالب `portswigger-notes/00-template.md` ويحتوي على:

1. **وصف الثغرة** — ما هي، وفي أي سياق تظهر.
2. **كيف استغلّيتها** — الطلبات والخطوات الفعلية (بدون تخمين).
3. **السبب الجذري (Root Cause)** — لماذا نجح الاستغلال على مستوى التصميم/الكود.
4. **المنع في Java Spring Boot** — كود أو إعدادات فعلية.
5. **درس مستفاد** — ما الذي سأغيّره في طريقة تفكيري أو مراجعة الكود.
6. **أسئلة للتفكير** — لاختبار الفهم بدلًا من الحفظ.

كل ملاحظة مكتوبة **بالعربية والإنجليزية**:
- العربية للفهم العميق والمراجعة السريعة.
- الإنجليزية للنشر على GitHub وتجهيز أمثلة المقابلة.
